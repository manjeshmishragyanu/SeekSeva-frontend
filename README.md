# SeekSeva

SeekSeva is a full stack platform where users can find people to help with daily tasks and services.

## Features

- User registration and login
- Service listing system
- Search for workers
- Contact or request help
- Responsive UI

## Tech Stack

Frontend
- React
- Vite
- CSS

Backend
- Node.js
- Express

Database
- MongoDB

README.md

## Installation

Clone the repository

git clone https://github.com/manjeshmishragyanu/seekseva.git

Move into the project folder

cd seekseva

Install dependencies

npm install

Start the development server

npm run dev
